# ⚖️ LegalTech MVP: Система финансового моделирования IP-проектов

## 📋 О проекте

Данная система разработана в рамках выпускной квалификационной работы (ВКР) НИУ ВШЭ и предназначена для автоматизации финансового моделирования проектов в области интеллектуальной собственности (IP).

**Ключевые возможности:**
- 💰 Автоматический расчет рентабельности проектов (NNE — Net Net Effective)
- 🏛️ Расчет налоговой нагрузки для России (РФ) и Казахстана (РК)
- 📊 KPI-метрики: Leverage, Margin, NNE
- 🎯 Реализация методологии **Дэвида Майстера** для профессиональных сервисных фирм (PSF)
- 🌍 Поддержка различных налоговых режимов двух юрисдикций

**Проблема, которую решает система:**  
Юридические и IP-фирмы часто не могут точно оценить прибыльность проектов из-за сложности расчета себестоимости, налогов и сквозных расходов (патентные пошлины). Система автоматизирует эти расчеты и помогает принимать обоснованные управленческие решения.

## 💡 Как использовать

1. **Выберите юрисдикцию** в боковой панели (🇷🇺 РФ или 🇰🇿 Казахстан)
2. **Укажите налоговый режим** (автоматически обновляется в зависимости от страны)
3. **Введите состав команды** в таблицу:
   - Имя и роль сотрудника (Partner, Senior, Associate, Junior)
   - Ставка для клиента (Billing Rate)
   - Внутренняя себестоимость (Cost Rate)
   - Количество часов работы
4. **Укажите патентные пошлины** (pass-through costs) — они добавляются к итоговой цене, но не облагаются налогами
5. **Просмотрите результаты:**
   - 💰 Итоговая цена для клиента
   - ⚖️ Leverage (эффективность использования младших специалистов)
   - ✨ NNE (чистая прибыль после всех вычетов)
   - 📊 Визуализация структуры цены

## 📊 Методология расчетов

### Налогообложение

**Российская Федерация (РФ):**
- УСН Доходы: **6%**
- УСН Доходы минус Расходы: **15%**
- ОСНО (НДС): **20%**
- НПД (Самозанятость): **6%**

**Республика Казахстан (РК):**
- Упрощенка СНР: **3%**
- ОУР (КПН): **20%**

### KPI Метрики

- **Leverage** = (Часы Junior + Associate) / (Часы Partner + Senior)  
  _Показывает, насколько эффективно используются младшие специалисты_

- **Margin** = (Выручка - Себестоимость) / Выручка × 100%  
  _Маржинальность проекта_

- **NNE** (Net Net Effective) = Выручка - Налоги - Себестоимость  
  _Чистая прибыль фирмы после всех расходов_
