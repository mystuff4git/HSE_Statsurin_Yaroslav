Структура базы данных

База данных спроектирована для управления учебным процессом и находится в 3-й нормальной форме (3NF).

Описание таблиц:

Таблица groups (Группы)

Хранит список учебных групп.

id: Первичный ключ (PK).

name: Название группы (уникальное).

Таблица students (Студенты)

Хранит личные данные студентов.

id: Первичный ключ (PK).

full_name: ФИО.

email: Уникальный email (с валидацией формата).

group_id: Внешний ключ (FK) к таблице groups.

Таблица teachers (Преподаватели)

Хранит данные преподавателей.

id: Первичный ключ (PK).

full_name, email, phone: Контактные данные.

Таблица subjects (Предметы)

Справочник предметов.

id: Первичный ключ (PK).

name: Название предмета.

category: Категория ('math', 'humanities') для аналитики успеваемости по направлениям.

Таблица grades (Успеваемость)

Основная таблица фактов.

id: PK.

student_id, teacher_id, subject_id: Внешние ключи.

grade_value: Оценка (ограничение CHECK: 1-5).

Целостность данных: Удаление студента удаляет оценки (CASCADE), удаление предмета запрещено при наличии оценок (RESTRICT).
